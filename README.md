# Офіційний веб-портал ВСП «БФКПЕП» із системою динамічного розкладу

Веб-платформа для Бердичівського фахового коледжу промисловості, економіки та права (ВСП «БФКПЕП»). 
Проєкт розроблено в рамках дипломної роботи (спеціальність 121 «Інженерія програмного забезпечення»).

## Головні можливості

- **Динамічний розклад та автозаміни пар**: замість сканованих таблиць та PDF з Viber — інтерактивна сітка пар для кожної групи із підсвіткою замін, аудиторій, викладачів та онлайн-посилань (Google Meet).
- **Парсер замін для диспетчерської**: швидкий імпорт текстових замін у форматі диспетчера або старости без зміни звичного робочого процесу.
- **Кабінет студента**: авторизація через корпоративний акаунт `@bfcpep.org.ua`, автоматичний підтяг розкладу своєї групи, доступ до Google Classroom та реквізитів на оплату (IBAN в 1 клік).
- **Повна відповідність вимогам МОН (Прозорість)**: структурований реєстр установчих документів, ліцензій, сертифікатів про акредитацію ОПП та фінансових звітів зі швидким пошуком і фільтрами.
- **Інтерактивний блок абітурієнта**: 8 спеціальностей коледжу, терміни вступу 2026 та калькулятор конкурсного балу (для 9 та 11 класів).
- **Сучасний UX**: світла та темна теми, адаптивність під телефони/планшети, миттєвий пошук по сайту.

## Стек технологій

- React 19 + Vite 8
- Vanilla CSS + CSS Custom Properties (дизайн-система без громіздких фреймворків)
- Lucide React (сучасні піктограми)
- LocalStorage state persistence (збереження вибраної групи, теми, користувача та кастомних замін)

## Запуск проекту

```bash
# Встановлення залежностей
npm install

# Запуск локального сервера розробки
npm run dev

# Збірка продакшн-версії
npm run build
```
